## 설명

웹툰 한 회차 제작 과정을 자동화하기 위한 Claude Code 하네스. README 기준 27개 전문 에이전트와 6개 스킬로 구성되며, 트렌드 조사, 시나리오 작성, 캐릭터 레퍼런스 시트 렌더, 패널 병렬 렌더, 생성-검증 루프, 세로 스크롤 뷰어 조립까지의 워크플로우를 다룬다.

## 메모

AI 기반 웹툰 제작 파이프라인, 에이전트 팀 구성, 패널 생성/검증 자동화 참고자료로 보관.
